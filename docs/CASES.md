# Selected campaign results

[Overview](../README.md) · [All expenses](EXPENSES.md) · [Method](METHOD.md)

These four campaigns were selected from the same 21-row export: the lowest observed unit cost for landing-page views, link clicks and messaging conversations, plus the largest messaging primary-result count. This is selection within the accessible record, not an industry benchmark or proof of sales.

## Campaign 20

Lowest primary landing-page-view cost in the export.

| Metric | Observed value |
|---|---:|
| Ad spend | $30.00 |
| Landing-page views | 105 |
| Cost per primary result | $0.29 |
| Impressions | 5,798 |
| Reach | 5,172 |
| Link clicks | 118 |
| Link click-through rate | 2.04% |
| Landing-page views | 105 |
| Reported end date | 2026-08-07 |

Calculation: $30.00 ÷ 105 = $0.29 per reported primary result, rounded to cents.

A messaging conversation is not a confirmed qualified lead or sale. A link click or landing-page view is not a purchase. Secondary actions can overlap and are not added to the primary result count.
