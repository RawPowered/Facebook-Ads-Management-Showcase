# Presentation graphics

`overview.png` presents the four selected campaigns. `cost-comparison.png` plots primary cost per response for every campaign with a primary count, separated by result type. Both are reconstructed from the anonymized data in this repository. Neither is an unedited Meta interface capture.

Graphics are limited to numerical performance reporting and typographic portfolio adaptations. Ad images, original post screenshots, advertiser creative and source-post links are excluded. The [copy examples](../docs/COPYWRITING.md) use clearly labeled anonymized text adaptations paired with original campaign metrics.

`selected-copy.svg` is an original typographic presentation of the polished portfolio adaptations and their corresponding original campaign metrics. It contains no source ad imagery or company identity. The displayed adaptations have not been run as ads.
